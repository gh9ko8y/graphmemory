the problem

记忆不是存储问题，是时间问题

把聊天记录塞进向量库，只解决了「找得到」。三个更本质的问题没解决：

01

时间

三个月前的「喜欢下雨天」和昨天的「喜欢晴天」，向量权重一样。人不会这样。

02

遗忘

所有记忆永久等权，噪音越积越多，检索越来越糊。遗忘是特性，不是缺陷。

03

变化

「他今年 26 岁」明年就错了；约定好的事过期了也不会被清理。记忆需要时效。

how it thinks

六变量：遗忘是降级，不是删除

每条记忆有六个维度。时间流逝时 D 缓慢下降、R 缓慢上升——直到淡出成一段「照片式片段」。原文账本永远保留，可追溯当时到底说了什么。

双时态：每条事实有两条时间轴——「有效时间」和「记录时间」，能回答「当时是什么」与「后来改了什么」。
